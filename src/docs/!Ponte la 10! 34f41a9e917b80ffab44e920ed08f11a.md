# !Ponte la 10!

# #Objetivo

Fidelizar a los clientes de farmacia incentivando la recurrencia de compra mediante mecánica de llenado de cartillas.

# #Flujo (UX)

1. **Ingreso:** El usuario ingresa su cédula. El sistema valida si existe:
    - **Usuario nuevo:** Se despliega formulario de registro (Nombre, Apellido, Cédula, Teléfono). Al completarlo, accede a su cartilla vacía.
    - **Usuario existente:** Accede directamente a su cartilla activa.
2. **Visualización de cartilla:** Se muestra el grid con los espacios llenos y vacíos, reflejando los puntos acumulados en tiempo real por compras en farmacia que superen el umbral definido.
3. **Cartilla completa:** Al alcanzar los 20 espacios, se activa el módulo de redención:
    - Se solicita permiso de geolocalización al usuario.
    - Se muestran en un mapa embebido las 4 farmacias más cercanas con disponibilidad de stock.
    - Las farmacias sin stock se muestran visualmente diferenciadas con un aviso de *"Sin disponibilidad"*.
4. **Planificación de retiro:** El usuario selecciona farmacia, fecha y hora de retiro. Se muestra un resumen para confirmación.
5. **Confirmación:** El sistema registra el retiro planificado y envía un SMS al número registrado con los detalles (farmacia, fecha y hora).
6. **Modificación de retiro:** El usuario puede ingresar nuevamente con su cédula y modificar la fecha, hora o farmacia de retiro, siempre que el premio no haya sido marcado como entregado por el administrador. Se envía un nuevo SMS con los datos actualizados.
7. **Nuevo ciclo:** Una vez el administrador marca el premio como entregado, la cartilla se cierra y el usuario puede iniciar una nueva para acumular puntos nuevamente.

# #Spec

### 1) Usuario

- Ingreso y registro del sistema
- Visualiza el proceso de sus puntos puntos acumulados.
- Cuando se complete la cartilla, puede ingresar fecha, hora y seleccionar Farmacia a la que va a hacer el retiro del premio.
- Al completar una cartilla y redimir el premio, el usuario puede iniciar una nueva cartilla para ganar otra camiseta. Con historial de reclamo de premios.

### 2) Panel Administrador

- Gestión de usuarios.
- Visualización de cuántas cartillas están en proceso y cuántas camisetas se han entregado.
- Marcar como premio entregado a la cartilla los usuarios.
- Carga de stock de camisetas por cada punto de venta.
- Descarga de la base de datos de usuarios (Cédula, Nombre, Teléfono).
